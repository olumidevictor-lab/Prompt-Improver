# Prompt Improver

A website that turns a rough, vague prompt into a clear, structured one that AI models actually follow.

Live site: https://improvemyprompts.netlify.app

![Prompt Improver screenshot](Screenshot%202026-11-19%20025731.png)

## How it works

1. Paste what you'd normally type.
2. Pick the AI you're writing for: ChatGPT, Claude, Gemini, or an image or video generator.
3. Get back a rewritten prompt with the missing context and format filled in.

Text prompts and image prompts need different structures, so the output changes with the target.

## Other features

Prompt history, plus optional accounts so your saved prompts follow you across devices.
